# Дизайн-система Afina2

## Тон

Современный банковский продукт: спокойный, дорогой, без визуального шума.
Акцент — доверие, скорость и ясность. Тёмная тема — равноправная, не «инвертированная».

## Компоненты

- **App shell**: sidebar 264px, topbar 64px, контент до 1440px.
- **Hero**: градиент primary→violet, белый текст, крупный заголовок 28px.
- **Stat card**: иконка 42px, значение 28px/800, подпись 13px.
- **Folder card**: иконка, счётчик, hover-подъём 2px.
- **Таблицы**: заголовок без фона, hover-строка, статусы-теги pill.
- **Модалки**: подписание, загрузка, командная палитра (⌘K).
- **Темы**: переключатель в topbar, сохраняется в localStorage.

## Правила

1. Один primary-акцент на экран; градиент — только для hero/CTA.
2. Статусы — цвет + иконка + текст (не только цвет).
3. Все действия с документами доступны с клавиатуры, у иконочных кнопок — `aria-label`.
4. Ошибки — человеческим языком, с подсказкой следующего шага.
5. Мобильная версия: sidebar-drawer, карточки вместо широких таблиц, touch-зоны ≥ 44px.
6. Никаких внешних CDN: шрифты и иконки — в бандле.

## Тема Ant Design

`ConfigProvider` + `theme.darkAlgorithm`; компонентные токены — `src/lib/theme.ts`.
