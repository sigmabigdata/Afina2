# Roadmap и паритет с AfinaZ

## Сделано (текущее состояние)

- [x] Монорепозиторий: React SPA + Spring Boot API + деплой
- [x] Портирование ядра AfinaZ в `ru.afina` (сущности, сервисы, JCSP, CRL, Госключ)
- [x] REST API `/api/v1` для всех разделов кабинета и админки
- [x] Аутентификация: magic-link, вход по сертификату (challenge + CAdES-BES)
- [x] Документы: загрузка, разделы, карточка, скачивание, `.sig`, ZIP «документ + подпись»
- [x] Подписание: плагин КриптоПро в SPA, проверка JCSP, CRL, визуализация, справка
- [x] Госключ: заявки, пакеты до 15 файлов, статусы, применение подписи
- [x] Шаблоны HTML → PDF, согласие на обработку ПДн, онбординг
- [x] Админка: клиенты, документы, аудит, CRL, настройки, мониторинг, бэкапы, ключи, МЧД, SSL
- [x] Безопасность: cookie-сессии, CSRF, CSP, rate limit, IP-whitelist, AES-256-GCM
- [x] Тесты: сервисные + интеграционные REST, smoke-скрипт, SBOM
- [x] Деплой: multi-stage образы, compose, Angie, скрипты

## Этап 1 — приёмка в контуре заказчика

- [ ] Установка на Astra Linux SE 1.8 + Axiom JDK Pro + КриптоПро CSP
- [ ] Подключение реального truststore УЦ и проверка строгого режима CRL
- [ ] Настройка SMTP и проверка magic-link на боевом домене
- [ ] Подключение API ЕПГУ для «Госключа» (адрес, токен, мнемоника, код услуги)
- [ ] Нагрузочное тестирование (100 одновременных пользователей)

## Этап 2 — сертификация и реестр

- [ ] SBOM и лицензионный аудит в CI (артефакты каждой сборки)
- [ ] Модель угроз и заключение по иностранным MIT-компонентам
- [ ] Матрица соответствия требованиям ФСТЭК/ИБ
- [ ] Документация: инструкция администратора, руководство пользователя
- [ ] Испытания и получение заключений

## Этап 3 — развитие

- [ ] Демо-стенд с изолированными арендаторами (`ru.afina.demo` уже портирован)
- [ ] Мастер первичной установки (setup wizard) в SPA
- [ ] Поиск по содержимому документов (PDF-текст)
- [ ] Уведомления в интерфейсе (in-app), а не только письмом
- [ ] Мобильная подпись через «Госключ» для всех сценариев
